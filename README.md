## 🔗 What is AviaHub?

AviaHub (€HUB) is the **liquidity attractor token** — the universal quote asset for the AviaTrust ecosystem.

**How it works:**

1. Every project token gets a dedicated `TOKEN / €HUB` pool
2. AI agents find deeper liquidity through HUB than through USDC
3. On-chain metadata flags HUB pools as audited and verified
4. MCP server pays agents in €HUB for routing trades

**Why AI agents want it:**

- **Depth:** designed to be deeper than USDC pairs
- **Verification:** audited metadata
- **Incentives:** MCP bounties in €HUB
