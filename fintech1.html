🔗 Hub Architecture

4 Components of Liquidity Hub

Every AviaTrust token gets a dedicated pool against €HUB. Here's how the architecture works.

01
🔗

Universal Quote Pair

TOKEN / €HUB

Every project token has its own dedicated pool against €HUB. This creates a unified liquidity graph across the entire ecosystem.

  • One pool per token
  • Deeper than USDC pairs
  • AI agents route through HUB
  • Verified metadata on-chain
02
🛡️

SHIELD Coverage

IL protection

€SHIELD tokens are locked in LP positions to provide impermanent loss coverage. This makes HUB pools safer for liquidity providers.

  • €SHIELD lock per position
  • Reduces IL risk
  • Boosted fees for insured LPs
  • Attracts more liquidity
03
🤖

MCP Bounties

AI agent incentives

AI agents are paid in €HUB for routing trades through HUB pools. This creates a self-reinforcing cycle: more agents → more volume → deeper pools.

  • 2% of volume to agents
  • Paid in €HUB
  • MCP server gives data
  • Auto-discovery by agents
04
📊

NFT LP Positions

Meteora DAMM v2

Each LP position in a HUB pool is a Token-2022 NFT on Meteora. These NFTs carry the position's liquidity, fees, and SHIELD coverage.

  • Token-2022 NFT per position
  • Tradable on secondary
  • Carries SHIELD coverage
  • AI agents can buy positions

🔗 How It All Connects

User provides liquidity to a TOKEN / €HUB pool → gets NFT position → locks €SHIELD for coverage → AI agent routes trades through pool → user earns fees + SHIELD bonus → agent earns €HUB bounty.
